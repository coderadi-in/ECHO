Installation

Let's see how you can install ECHO in your device.

It's Simple

Launching ECHO

When you launch ECHO and you haven't installed it in your device, you'll get an installation prompt and just by clicking the Install button, you can get started.

This works on every device, you don't need another process, it's same over all devices.
